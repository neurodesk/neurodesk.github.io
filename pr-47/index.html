Neurodesk components

Section titled “Neurodesk components”

Flexible tools that work together or independently. Neurodesk makes it easy for beginners and experts to use biomedical imaging tools on desktop, HPC, web, and cloud.

Neurodesktop

Complete virtual desktop environment with GUI applications, ready to use in your browser or locally.

  • 100+ pre-installed neuroimaging tools
  • Familiar desktop interface for graphical applications
  • Install Neurodesk once, all tools are ready to use

Neurocontainers

Individual containerised tools you can use in your own pipelines and workflows.

  • Transparent, version-controlled builds
  • Use via Docker or Singularity
  • Perfect for HPC and cloud

Neurocommand

Command-line tool manager that fetches and runs containers seamlessly.

  • Simple module-based interface
  • Integrates with existing workflows
  • Accessible through Neurodesk for command-line workflows
$ pip3 install -r neurodesk/requirements.txt --user
$ bash build.sh --cli
$ bash containers.sh
$ module use $PWD/local/containers/modules
