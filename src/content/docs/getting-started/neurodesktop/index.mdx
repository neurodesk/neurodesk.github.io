## Python notebook environments

Try [Python environments with uv](/getting-started/neurodesktop/uv-environments/)
to give an analysis folder its own packages and Jupyter kernel. This is an opt-in
prototype; the guide covers setup, package installation, persistence, and removal.

## Remote HPC jobs

[Submit an analysis to a remote Slurm cluster](/getting-started/neurodesktop/remote-jobs/)
with the experimental `neurodesk-jobs` CLI. DataLad and SSH transfer inputs and
results; the guide covers site configuration, submission, recovery, and verified
archives. Bunya and Sherlock templates require site validation before research use.

## Tool citations

Neurodesktop records the Neurodesk tools that you load. Run `neurodesk-cite` in a
terminal to write a `CITATIONS.md` file with methods sentences and references for
those tools. See [Generate a citation list with neurodesk-cite](/overview/how-to-cite-us/#generate-a-citation-list-with-neurodesk-cite)
in the Citation Guide.
