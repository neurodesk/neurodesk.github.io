# Neurodesk Design Style Guide

This style guide provides clear standards to ensure visual consistency across all Neurodesk platforms and materials.

## Brand overview

Neurodesk is a community-oriented open-source solution for neuroimaging analysis with four guiding principles: accessibility, portability, flexibility and, overarchingly, reproducibility. This guide ensures visual consistency across all Neurodesk products and documentation.

## Where these files live

All Neurodesk visual assets are stored in the [`neurodesk/media`](https://github.com/neurodesk/media) repository, which is the single source of truth. This page explains how to use them; the repository holds the files themselves.

If an asset is missing, or you need a variant that doesn't exist, [open an issue](https://github.com/neurodesk/media/issues/new/choose) rather than editing an existing file.

## Licensing and permitted use

Two different sets of terms apply, and the distinction matters.

| What | Terms |
|---|---|
| Figures, diagrams, and screenshots | [CC BY 4.0](https://github.com/neurodesk/media/blob/main/LICENSE) — reuse freely with attribution |
| The Neurodesk **name and logo** | Project marks — **not** CC BY |

Attribution string: `Neurodesk (https://neurodesk.org), CC BY 4.0`

### You may, without asking

- Use an unmodified logo to link to neurodesk.org or a Neurodesk repository.
- Use an unmodified logo in slides, posters, papers, or blog posts that describe, teach, review, or cite Neurodesk.
- State truthfully that your tool, pipeline, or course uses or supports Neurodesk.
- Scale the logo proportionally, and choose whichever variant reads best on your background.

### Please ask first

Open an issue on [`neurodesk/media`](https://github.com/neurodesk/media/issues/new/choose), or email [mail.neurodesk@gmail.com](mailto:mail.neurodesk@gmail.com), before you:

- Change the logo's colours, proportions, typography, or artwork.
- Combine it with another mark into a new lockup.
- Use it on merchandise, event branding, or in a domain name.
- Use it in a way that could imply Neurodesk endorses or certifies your product.

Neurodesk is a community project and generally says yes — asking is mostly so we know it is happening.

Full detail is in [BRAND.md](https://github.com/neurodesk/media/blob/main/BRAND.md).

### Which variant should I use?

| Context | Variant |
|---|---|
| Light or neutral background | the standard variant |
| Dark background | the `-on-dark` variant |
| Wide header, one line of space | the `-horizontal` variant |
| You want the web address visible | the `neurodesk-org-` prefix |
| Pride and inclusivity contexts | the `-pride` variant |

<Aside type="caution" title="Raster only">
Every logo above is currently PNG. There are no vector (SVG) masters, so the logo cannot be scaled cleanly for a large-format poster or a print run. If you need the logo at print size, [open an issue](https://github.com/neurodesk/media/issues/new/choose) before scaling a PNG up.
</Aside>

## Naming and capitalisation guidelines

To ensure consistency in our branding, please follow the guidelines below when referring to Neurodesk and its associated tools.

### Correct usage

- **Neurodesk**: capitalise only the first letter.
  - `neurodesk` or `NEURODESK` may be used where the surrounding style calls for it, such as an all-caps heading or a lowercase URL.
- Use **"Neurodesk"** to refer to the overall project, platform, or community.
- Use consistent casing in product names:
  - **Neurodesktop**
  - **Neurocommand**
  - **Neurocontainers**
  - **NeurodeskApp**

### Do not use

Avoid the following incorrect variations:

- `neuroDesk` — internal capital
- `NeuroDesk` — internal capital
- `Neuro Desk` — space in the middle
- `neurodesk` in running prose, titles, or headings, where **Neurodesk** is correct

## Typography

### Font families for website

- **Logo:** Scirich — see below
- **Headings:** Pontano
- **Body text:** Pontano
- **Code blocks:** Menlo

### Scirich Regular

Scirich is a modified version of [Aldrich](https://fonts.google.com/specimen/Aldrich) by
Matt McInerney, adapted and renamed by Michèle Masson-Trottier. It is licensed under the
[SIL Open Font License 1.1](https://raw.githubusercontent.com/neurodesk/media/main/font/LICENSE.txt), as is the original.

- [Download `Scirich-Regular.ttf`](https://raw.githubusercontent.com/neurodesk/media/main/font/Scirich-Regular.ttf) — installable font
- [Download `Scirich-Regular.sfd`](https://raw.githubusercontent.com/neurodesk/media/main/font/Scirich-Regular.sfd) — FontForge source, for editing
- Upstream: [micmas/Scirich-font](https://github.com/micmas/Scirich-font)

If you redistribute it, the OFL requires you to include the full licence, avoid the
reserved name "Aldrich", attribute the original designer, and describe your changes.

When exporting a logo or figure to SVG, convert text to paths so it renders correctly for people who do not have these fonts installed.

## Contributing an asset

To add a figure, diagram, or screenshot to the shared library, see [CONTRIBUTING.md](https://github.com/neurodesk/media/blob/main/CONTRIBUTING.md) in the media repository. In short: use the naming convention, commit a vector master where one exists, keep files under the size limits, and update the folder's README table.
